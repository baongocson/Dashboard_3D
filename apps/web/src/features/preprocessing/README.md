# Pre-processing

Workbench dùng operationSchema chung, tạo preview qua Worker và chỉ Apply sau durable publication. Các mục Cleaning/Missing/Outlier/Scaling/Transformation/Encoding dùng cùng current dataset; chart source/result giữ riêng theo mục. previewRules cung cấp kiểm tra giá trị nhập và các helper tương thích hợp đồng fill-cell.
